# 0.1 验证记录

环境：Apple Silicon Mac，Node.js 24，Electron 44.5.1。

## 已验证

- TypeScript 编译及生产界面构建。
- 12项核心自动测试：尺寸扣分连续性及边界、等级边界、尺寸交换、尺寸浮点误差、D触发、照片质量不扣分、缺失证据暂评、无效模型输出拒绝。
- Responses 和 Chat Completions 两种协议的本机模拟 HTTP 请求、结果解析、认证失败提示及取消。
- 实际 Electron 窗口启动、中文布局、六面照片导入与重新导入、尺寸填入。
- API 配置保存、重启后读取，未配置密钥时禁止连接测试。
- 主进程到本机模拟接口到报告页的完整流程、报告文件持久化、Markdown 导出、历史删除、缺失指标暂评、分析取消。
- 离线演示明确标注，不产生真实历史记录。

桌面全流程使用独立临时数据目录和模拟 API；测试进程中替换了密钥解密函数，未读取用户真实钥匙串。生产代码使用 Electron safeStorage，用户已完成真实密钥配置及 DeepSeek 视觉分析。

## 尚未验证

- 更多模型及第三方接口的兼容性（仅收到用户 DeepSeek 单次成功反馈）。
- 实际单次分析费用、耗时。
- 核桃判断准确性、跨重复调用的稳定性、权重及等级校准。
- Apple签名、公证及其他电脑上的安装兼容性。

桌面交互测试命令：`npm run test:desktop`，使用脚本生成的测试图片，无需真实商家照片或 API 密钥。
