# 0.1 验证记录

环境：Apple Silicon Mac，Node.js 24，Electron 44.5.1。

## 已验证

- TypeScript 编译及生产界面构建。
- 12项核心自动测试：尺寸扣分连续性及边界、等级边界、尺寸交换、尺寸浮点误差、D触发、照片质量不扣分、缺失证据暂评、无效模型输出拒绝。
- Responses 和 Chat Completions 两种协议的本机模拟 HTTP 请求、结果解析、认证失败提示及取消。
- 实际 Electron 窗口启动、中文布局、六面照片导入与重新导入、尺寸填入。
- API 配置保存、重启后读取，未配置密钥时禁止连接测试。
- 主进程到本机模拟接口到报告页的完整流程、报告文件持久化、Markdown 导出、历史删除、缺失指标暂评、分析取消。
- 离线演示明确标注，不产生真实历史记录。

桌面全流程使用独立临时数据目录和模拟 API；测试进程中替换了密钥解密函数，未读取用户真实钥匙串。生产代码使用 Electron safeStorage，用户已完成真实密钥配置及 DeepSeek 视觉分析。

## 尚未验证

- 更多模型及第三方接口的兼容性（仅收到用户 DeepSeek 单次成功反馈）。
- 实际单次分析费用、耗时。
- 核桃判断准确性、跨重复调用的稳定性、权重及等级校准。
- Apple签名、公证及其他电脑上的安装兼容性。

桌面交互测试命令：`npm run test:desktop`，使用脚本生成的测试图片，无需真实商家照片或 API 密钥。


0.1.1 修复：兼容 JSON 模式显式提供完整 JSON Schema 和六视角、九指标的格式示例；结构错误指出缺失字段，保留严格校验。使用本机模拟接口验证，未调用用户 DeepSeek 密钥，随后用户确认真实 DeepSeek 分析成功：88.5 分、A级。尚未验证重复稳定性。


## 0.1.2 本地验证

15项自动检查通过；模拟接口验证仅正面、顶、底三张照片仍能提交，并显示86.7分、暂评A及低可信度。请求仅含三张图片，缺失棱边不计入可评满分。历史保存和Markdown暂评标记验证通过。估分按已评权重折算，尚未通过真实缺图样本验证准确性。未调用付费API。


## 0.2.0 本地验证

25项核心自动检查通过：尺寸全空和部分、40与40.0等价、无效尺寸拒绝、三棱八视角结构、动态协议请求、细节ID与照片证据校验、文字描述不视为确认事实、细节不替代整体视角及旧格式兼容。

桌面模拟流程通过：三棱八张整体图加一张细节图正常提交；全空尺寸得到仅视觉评级，部分尺寸正确扣分；多条细节记录和文字未核实提示显示正常；中文导出、历史保存／删除、旧版报告查看和取消正常。

全程使用隔离数据目录、项目自有图标和本机模拟API，未读取真实密钥或调用付费服务。新增三棱和细节观察的真实准确性仍需样本验证。
