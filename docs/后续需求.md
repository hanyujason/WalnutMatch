# 志愿者反馈与后续需求

## 已实现：缺图暂评（0.1.2）

至少一张双颗同框照片即可提交。只发送已有照片；缺失视角写明未提供。仅依据可判断项目折算估分并扣尺寸差，等级标记暂评，可信度低。不把缺失项目当0分或满分。已评得分、已评权重和缺失视角保留在报告里。估分未经过样本校准。

## 待实现：棱数与拍摄模板

- 两棱：两个肚面、两个棱边、顶部、底部。
- 三棱：三个侧面、三个棱边、顶部、底部；全部槽位允许留空。
- 只提供两棱、三棱选项，默认两棱；暂不实现异形。
- 棱数由用户选择，不根据品种名称猜测；允许记录两颗棱数不同。
- 数据格式改为每张照片有独立视角ID，提示、分析、证据引用和导出统一跟随模板。旧版六面报告仍可查看，不能强行将三棱塞进两棱六面。
- 比较棱数、棱边排列、截面与整体形态；权重是否独立调整需用三棱／异形样本验证。四棱以上仅作为产品分类，不代表市场品种分类。

## 待实现：细节补充

每条补充包含文字、可选照片、所属核桃（左／右／两颗／未知）、位置标签，可增加多条。文字属于用户描述，图片可见内容属于模型观察，二者分开展示。黄尖、黄丝、磕碰、色差先只做备注，不直接扣现有形状／纹路配对分。新增瑕疵评分前另行定义规则。输入作为待观察资料，不得作为改变评分规则的指令。

## 补充已确认需求（待实现）

- 上传区域增加清晰拍摄、统一朝向、正对拍摄面、光线均匀及避免手指遮挡的提示，三棱强调顶部布局。
- 尺寸选填；全部不填仅视觉评级，不降低照片可信度。部分填写仅比较两颗都填写的同一维度，未比较的尺寸标记缺失；仍使用既有尺寸扣分规则。空白不是0，无效数字须修正，40与40.0相等。
- 细节补充不填写不影响评分或可信度；细节图不能自动替代缺失整体视角。
