# 志愿者反馈实现记录

## 0.2.0 已完成

- 两棱／三棱选择，默认两棱，不包含异形。
- 两棱六视角、三棱八视角；棱边布局对应分析，权重保持形状60／纹路40。
- 清晰拍摄、统一朝向、正对拍摄面、光线均匀及避免手指遮挡提示。
- 多条可选细节文字、图片、所属核桃和位置；用户描述与模型观察分开，黄和磕碰等仅备注。
- 尺寸选填；全空仅视觉评级，部分只比较共同项；40与40.0相等，空白不等于0。
- 细节图不能代替缺失整体视角；未填写尺寸和细节不降低照片可信度。
- 历史与中文／JSON导出包含新字段，旧报告兼容且不重算。

## 继续保留

缺图暂评：至少一张整体同框照片即可提交，按已评项目折算到100分再扣尺寸差，标为暂评和低照片可信度；全部无法判断时不出分。

## 待验证

真实三棱样本、细节观察、缺图估分的准确性和重复稳定性。暂不实现异形、单只库、批量配对、瑕疵扣分或价格评估。
