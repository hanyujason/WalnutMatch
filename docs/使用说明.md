# WalnutMatch 桌面版 0.1

用于比较一对文玩核桃的六面形状、纹路和实测尺寸。中文界面，报告保存在本机；点击分析时，照片发送到你配置的 API 服务。结果仅供配对参考，不构成品相鉴定或价格评估。

## 首次使用

1. 打开 WalnutMatch.app。
2. 进入「API 设置」，选择协议，填写基础地址、视觉模型名称和密钥。
3. 点击「保存设置」。密钥通过 macOS 系统密钥机制加密后保存，不写入报告，不显示原密钥。
4. 点击「测试已保存配置」。这会发送一次简短文本请求，可能产生少量费用；成功不代表模型支持图像。
5. 返回「对子评分」，导入六张双颗同框照片，填写边宽、肚宽、桩高。
6. 勾选照片发送说明，点击「开始配对评分」。

六张照片对应两个肚面、两个棱边、顶部、底部。默认是同一对核桃，不做跨照片身份核验；实测尺寸无需对应照片左右。当前面向同品种对子，尺寸需要完整填写。

API 基础地址例如 `https://api.openai.com/v1`，不要在末尾添加 `/responses` 或 `/chat/completions`。OpenAI 使用 Responses；其他兼容服务可选择 Chat Completions。必须使用支持图像输入的模型，纯文本模型不可用。并非所有第三方服务都支持同样的字段和 JSON 输出模式。

严格结构化输出使用 JSON Schema。如果服务返回 400 且不支持此功能，可以取消勾选严格模式，保存后再试。兼容模式仍要求 JSON 输出，程序会验证六个视角、九项指标、差异档及照片依据，验证失败不会生成评分。

## 报告与数据

- 视觉分析由模型完成；差异档映射、尺寸扣分、等级由程序计算。
- 形状满分 60，纹路满分 40。尺寸接近不加分，三项差值分别扣分。
- 可信度是照片证据充分程度的高/中/低提示，不是统计准确率。
- 缺失指标或不可用视角时，只生成局部分析，不生成完整总分和等级。
- 任一尺寸差≥2mm 触发 D，报告保留视觉分，并注明尺寸不适配。
- 单项保留精度参与计算，总分显示一位小数；等级按未舍入的最终分判定。
- 每次真实分析单独保存到历史。离线演示使用预设内容，不分析你的图片、不调用 API，也不保存到历史。
- 导出中文报告为 Markdown；完整 JSON 数据包含处理后的六张照片、结构化分析和用量，不包含密钥。
- 可从历史中删除单份报告，删除前会要求确认。

数据默认位于 macOS 的 `~/Library/Application Support/WalnutMatch/`（开发运行时可能使用 `walnutmatch` 目录）。配置在 settings.json，密钥密文在 key.enc，报告在 reports 文件夹。首版采用独立 JSON 报告文件，尚未使用 SQLite。不要把 key.enc 上传到 GitHub；跨电脑复制密文也无法保证能解密。

导入图片会保持比例缩小到长边最多 1800 像素，以 JPEG 92% 质量保存分析副本。原始文件不修改，应用不另外备份原始文件，请自行保留原图。报告保存的是分析副本。商家参考照片没有包含在发布包里。

## 网络与失败处理

请求最长等待四分钟，可点击取消。401/403 检查权限，429 检查额度或频率；400 检查模型、协议和输出模式。程序不会偷偷切换模型或自动重试产生额外分析费用。

应用用主进程发起请求，不直接访问聊天软件，不继承其订阅或登录。首版没有单独的代理配置界面；如果网络需要代理，请使用能让应用网络正常连通的环境。连接失败会保留照片与尺寸，方便重试。

## 当前限制

评分规则为实验草案，尚未通过大规模样本校准。模型仍可能误判或波动，固定规则不能保证视觉判断稳定。不同模型结果不能直接当作同一量尺。暂无批量自动配对、单只库、瑕疵检测、价格评估和跨图身份检查。

应用是本地测试版，未做 Apple 开发者签名和公证。macOS 可能要求通过系统提供的打开方式确认来源，发布给其他用户前应补签名与公证。
