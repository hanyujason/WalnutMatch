# WalnutMatch 0.2.0 使用说明

1. 打开WalnutMatch.app，在API设置中填写视觉模型、接口地址和密钥，保存配置。文本连接测试可能产生少量费用，不能证明图像分析可用。
2. 选择两棱或三棱，导入已有整体同框照片，至少一张。
3. 尺寸和细节补充均为选填，勾选发送说明后点击开始配对评分。

## 拍摄模板

两棱：两个肚面、两个棱边、顶部、底部，共六视角。
三棱：三个侧面、三个棱边、顶部、底部，共八视角。

两颗同框摆正、保持相同朝向，镜头正对所拍面。使用均匀光线、简洁背景，拍清完整轮廓和纹路，避免手指遮挡棱、尖和底。三棱顶部尽量完整展示三条棱。“正奔对正奔、Y字对Y字”只是参考，仍比较间距、宽厚和偏向，不直接等于高分。

缺少视角可以留空，评分会标为暂评。切换类型保留图片方便返回原模板；隐藏的第三侧面／第三棱边不会发送，切换后请核对照片视角和朝向。不做跨照片身份核验，也不要求左右跨图一致。

## 可选尺寸

填写边宽、肚宽、桩高，单位默认毫米，不加mm。40与40.0相同，支持小数；有效值大于0、不超过100。空白表示未提供，0、负数或无效数字须修正。

- 全部留空：仅视觉评级，未计尺寸扣分。
- 部分填写：只比较两颗都填写的同一项；单方填值不当成另一颗为0。
- 完整填写：包含尺寸比较的评级。尺寸无需对应照片左右。

未填尺寸不降低照片可信度；报告明确显示已比较范围。各项差≤0.5mm不扣，0.5–1mm连续扣0–3分，1–2mm连续扣3–12分，≥2mm单项扣12分并触发D。只对可比较项目累加。

## 可选细节

最多8条，每条文字最多2000字，可填所属核桃、位置和一张局部照片。不填写不影响评分或可信度，空白条目不发送。左右对象以这张细节照片为准。

报告分开展示用户描述与模型观察。仅有文字会标记“仅用户描述，未提供细节照片，无法核实”；有图则说明可见内容与不确定性。黄、磕碰、色差等只备注，不直接扣现有形状／纹路分。局部纹路图可辅助分析，不能替代缺失整体视角。

## 评分与报告

形状60分、纹路40分；模型输出差异档，程序计算分数和等级。缺图或指标未知时，用已评项目得分／满分×100估分后扣尺寸差，明确标记暂评；全部无法判断不出分。等级按未舍入值判定，显示总分一位小数。

照片可信度是证据充分程度，不是准确率。规则为实验草案，结果仅供配对参考，不构成品相鉴定或价格评估。

真实分析自动进入历史；离线演示为预设结果，不调用API，不写历史。旧报告继续按原规则记录查看，不重算。中文报告为Markdown；完整JSON包含处理后的整体及细节图片、类型、用户描述、模型观察、分析及用量，不包含密钥。历史删除需要确认。

## API与本地数据

基础地址不要加/responses或/chat/completions。服务不支持JSON Schema时可取消严格结构化输出，程序仍校验当前模板和九项指标。必须配置支持图像输入的模型。

分析时图片和补充文字会发送到配置的服务商。请求最多等待四分钟，可以取消，不自动重试或切换模型。401/403检查权限，429检查额度或频率，400检查模型与格式支持。

本地配置与报告在 ~/Library/Application Support/WalnutMatch/，密钥密文key.enc，配置settings.json，报告reports/。不要上传这些文件到GitHub，跨电脑复制密文未必可解密。

图片等比例缩到长边最多1800像素，以JPEG 92%保存分析副本，原图不修改。发布包不含商家原图。M系列Mac已做启动测试，未签名、公证；其他系统未验证。
